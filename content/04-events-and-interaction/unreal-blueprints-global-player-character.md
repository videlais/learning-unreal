# Unreal: Blueprints: Global: Player Character

> Legacy lesson, organized for self-study. Screenshots may show an older editor. See the Unreal 5.8 verification scope (legacy attachment omitted) before relying on version-specific steps.

We often need to access the player character, which is itself based on the Character class. There is a node for that: [Get Player Character](https://dev.epicgames.com/documentation/en-us/unreal-engine/BlueprintAPI/Game/GetPlayerCharacter). We can always reach the "playing" character moving around in some level.
