# Unreal: Blueprints: Getting and Setting

> Legacy lesson, organized for self-study. Screenshots may show an older editor. See the Unreal 5.8 verification scope (legacy attachment omitted) before relying on version-specific steps.

When we work with variables in Unreal, we perform one of two actions: get or set.

When we want to access the value of a variable, we perform a *get* action.

When we want to change the value of a variable, we perform a *set* action.

If a variable is instance editable (public) in Unreal, we can "get" and "set" its value in some way.
