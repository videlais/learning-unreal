# Unreal: Portfolio: Résumé are claims, portfolio is evidence

> Legacy lesson, organized for self-study. Screenshots may show an older editor. See the Unreal 5.8 verification scope (legacy attachment omitted) before relying on version-specific steps.

A résumé is a "summary" of important skills, life events, and achievements. It literally means, borrowed from French, "to summarize"

As part of this role, the résumé should serve as a set of *claims*. You state that you can use certain tools to some degree or have created project showing certain patterns. If an employer is interested in you, they will then move to the portfolio itself.

The portfolio should serve as *evidence*. For example, if you state that you have crated project in Unity or Unreal, you *must* have examples of projects in those engines or links to your name listed as having worked on them. If you are claiming you are a level designers, you should have some evidence to back that claim up.
