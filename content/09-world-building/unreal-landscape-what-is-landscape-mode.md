## *What is the Landscape Mode?*

We often want to define terrains and environments. The Landscape Mode allows for creating valleys, hills, plains, and mountains easily as part of a "paint" process called *sculpting*.

### Landscape Mode Tabs

The Landscape panel has three main tabs:

- Manage: Create, modify, and manage landscape components
- Sculpt: Shape and modify terrain height
- Paint: Apply material layers to the landscape

## Creating landscape

We create changes in landscape through using the *Sculpt* tab.

The basic terrain shaping tool:

1.  Select Sculpt from the tool list.
2.  Left-click and drag: Raises terrain.
3.  Shift + Left-click and drag: Lowers terrain.
4.  Adjust settings:
    - Brush Size: Size of the affected area.
    - Brush Falloff: How quickly the effect fades at edges (0.0 to 1.0).
    - Tool Strength: Intensity of the sculpting effect.
