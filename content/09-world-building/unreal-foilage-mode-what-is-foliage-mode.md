# Unreal: Foilage Mode: What is Foliage Mode?

> Legacy lesson, organized for self-study. Screenshots may show an older editor. See the Unreal 5.8 verification scope (legacy attachment omitted) before relying on version-specific steps.

The Foliage system allows for *instancing* a static mesh hundreds or thousands of time in a single level. This allows for having, for example, a large amount of grass, bushes, or trees without treating each of them as its own static mesh.

## Adding Foliage

For each static mesh to treat as foliage, it must be dragged from the Content Drawer into the Foliage listing.

This will prompt saving the static mesh as a new asset as a Foliage type.
