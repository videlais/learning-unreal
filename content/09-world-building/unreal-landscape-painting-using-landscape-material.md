# Unreal: Landscape: Painting using Landscape Material

> Legacy lesson, organized for self-study. Screenshots may show an older editor. See the Unreal 5.8 verification scope (legacy attachment omitted) before relying on version-specific steps.

## Adding Landscape Material to Landscape

- If you already have a Landscape actor, access its Details.
- Scroll down to its Landscape section.
- Select Landscape Material and select the prepared material.

![Screenshot highlighting Landscape Material option.](../media/Screenshot%202025-11-16%20at%207.07.43%E2%80%AFPM.png)

*Figure: Screenshot highlighting Landscape Material option.*

## Creating Landscape Layers from Material

- Switch to Landscape Mode if not already in it.
- Select "Paint"
- In the bottom, find the *Layers*.
- Click on "Create Layers from Assigned Material"

![Screenshot for Landscape Mode and Paint tool.](../media/Screenshot%202025-11-16%20at%207.25.20%E2%80%AFPM.png)

*Figure: Screenshot for Landscape Mode and Paint tool.*

This will auto-populate the layer information.

![Screenshot showing Landscape Layer Blend layers.](../media/Screenshot%202025-11-16%20at%207.31.33%E2%80%AFPM.png)

*Figure: Screenshot showing Landscape Layer Blend layers.*

## Adding Landscape Layer Information Per Layer

To paint with the layers, additional files must be created named Landscape Layer.

For every layer in Paint tool, click on the "+" icon to create this file.

Save this file in the default location.

![Screenshot showing default save location for Landscape Layer file.](../media/Screenshot%202025-11-16%20at%207.38.46%E2%80%AFPM.png)

*Figure: Screenshot showing default save location for Landscape Layer file.*

The Content Drawer will open, showing the Landscape Layer.

![Screenshot showing created Landscape Layer information file.](../media/Screenshot%202025-11-16%20at%207.39.01%E2%80%AFPM.png)

*Figure: Screenshot showing created Landscape Layer information file.*

Close the Content Drawer.

## Painting using Landscape Blend Layers

By default, the initial drawer layer will be full black. To change this, we need to paint with the layers based on their layer information.

With the Paint tool, in the Landscape Mode, select a specific layer.

Click on the landscape to "paint" the use of the material, overriding the previous default black.
