# Unreal: Data Structures: Arrays

> Legacy lesson, organized for self-study. Screenshots may show an older editor. See the Unreal 5.8 verification scope (legacy attachment omitted) before relying on version-specific steps.

Similar to other programming languages, Unreal also supports the data structure **array.**

**An array is an ordered collection of multiple elements where access is defined by position.**

When we create variables, we can create them as arrays or use data from other nodes as an array.

## Array Functionality

- **Add:** Appends an element to the end of the array.
- **Insert:** Places an element at a specific index.
- **Remove:** Deletes an element at a specific index.
- **Get:** Retrieves an element at a specific index.
- **Length:** Returns the total number of elements in the array.
- **Clear:** Removes all elements from the array.
- **Contains:** Checks if a specific element exists in the array.
- **Find:** Returns the index of a specific element.

## For Each Functionality

Arrays support the **For Each Loop** node to access each element in the array.
