# Unreal: What is Unreal?

> Legacy lesson, organized for self-study. Screenshots may show an older editor. See the Unreal 5.8 verification scope (legacy attachment omitted) before relying on version-specific steps.

**Unreal is a game engine created and maintained by the company Epic Games.**

The Unreal game engine is often chosen to create visually impressive games because of the multi-year investment of Epic Games in rendering (drawing shapes) processes and the purchase of multiple technologies such as Nanite for virtualized geometry, Lumen for global illumination and reflections, and Virtual Shadow Maps to help make its output visually impressive.

It has a long history of being used to create video games (beginning in the early 2000s) and has increasing been used for virtual production (beginning in 2005) to create virtual production and sets for filming. More recently, it has been used for real-time filming with the show *The Mandalorian* beginning in 2020.

**As a game engine, Unreal manages different systems for a developer.**

Rather than have a developer need to write their own code to handle drawing shapes or handling input, Unreal provides a large number of systems and sub-systems. To use these, developers write code using a *programming interface* provided by Unreal. When a project is built, Unreal converts the programming into instructions for these systems to drive an experience.

**Unreal provides an interface to working with its systems named Blueprints, a visual scripting language.**

Unreal supports two programming languages, C++, a textual language invented in the 1970s, and Blueprints, a visual scripting language adopted in 2014 and previously named Kismet. (Although nearly all gone, some older systems in Unreal still use the name "Kismet" for things.)
