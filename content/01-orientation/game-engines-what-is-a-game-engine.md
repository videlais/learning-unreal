# Game Engines: What is a game engine?

> Legacy lesson, organized for self-study. Screenshots may show an older editor. See the Unreal 5.8 verification scope (legacy attachment omitted) before relying on version-specific steps.

**A game engine *drives* an experience.**

When we use the term, we are describing a collection of software designed to solve common issues in video game development including drawing shapes to the screen, handling different forms of player input, and managing media such as images and videos. We use game engines to focus more on the design of an experience rather than re-writing common code shared across projects.

**By using a game engine, developers can focus more on the creative aspects of game design rather than the technical details.**

Because game engines sit "between" a developer and low-level code accessing hardware and handling data for them, they all provide a *programming interface* through which a developer can write code for the engine rather than any particular hardware system.
